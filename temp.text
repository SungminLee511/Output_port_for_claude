F1  Fixed composition, uniform source: the reference control is wrong.
    constructions/fixed_composition.py `_value_table` uses log f1 = -E/tau whenever the source
    is not a Dirac, and `_control_error` and `oracle_law` inherit this. With a uniform source
    nu0 on Omega_{n,k}, the Schrodinger-bridge potential is f1 = mu / fhat1, where
    fhat1(z) = sum_x nu0(x) f0(x) P01(x,z) and f0 = 1/(P01 f1); this is not constant. The
    reported control_rel_err of 0.114 (L=4, uniform source) is therefore invalid. Exact TV is
    unaffected.
    Resolve: compute f1 by Sinkhorn on the enumerated L=4 space (12,870 states). Use
    P01(x,y) = kappa_{0,1}(d(x,y)) from the Johnson orbit kernel, applied through the overlap
    sums already in `_value_table` (P01 is symmetric). Iterate f0 <- 1/(P01 f1),
    fhat1 <- P01(nu0 * f0), f1 <- mu/fhat1 until both marginal errors are < 1e-12. Then
    recompute control_rel_err and oracle_tv for the three L=4 uniform-source seeds.
    Admit: drop the control error for uniform-source rows.

F2  Stiefel, Haar source: the corrector is missing.
    constructions/stiefel_4_2.py `terminal_grad` and the `build` docstring claim that fhat1 is
    constant under a Haar source because the reference preserves Haar. This is false:
    fhat1(Y) = int p^St_{0,1}(Y|X) f0(X) dHaar(X), and f0 = 1/phi0 is not constant unless the
    reference mixes completely by t = 1. Affected rows: stiefel_st42_frame_haar_tau1 and
    stiefel_st42_quad_haar_tau{0.769231,0.5,0.2}.
    Resolve: add a learned corrector h_psi(Y) ~ ambient grad log fhat1(Y), trained exactly like
    sphere.TerminalScore. Use a squared loss on the kernel score grad_Y log p^St_{r_{0,1}}(Y|X0)
    of the buffered source point, computed by left invariance:
    p^St(Y|X0) = p^St(g0^{-1} Y | E0), with g0 = section_lift(X0), then `log_pst` and autograd.
    Set G = -grad E/tau - h(Y). Rerun the four Haar rows with their original commands, 3 seeds.
    Admit: remove the Haar Stiefel rows from the reported set.
    In both cases, correct the docstrings.
