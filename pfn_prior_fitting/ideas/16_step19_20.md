# Steps 19–20 — the θ-conditional scorer, and scoring real data.

## 19. Architecture (`pfnfit/model.py`) and pretraining (`pfnfit/train.py`)

TabPFN-v2-style **2D attention** over a (rows × features) grid: alternating ROW
attention (across rows, within a feature column) and FEATURE attention (across
features, within a row). No positional embedding on either axis, so the model is
equivariant to feature permutation and exchangeable across rows up to the causal
order.

The point of the design is the **dual stream**:

```
C[i,j] = emb(x_ij) + emb(y_i)      context stream, carries the label
Q[i,j] = emb(x_ij)                 query stream,   never carries y_i

ROW:  Q <- cross-attend to [BOS, C[0..i-1]]   (strictly causal)
      C <- self-attend  to [BOS, C[0..i]]     (causal, inclusive)
```

The head reads `Q[i,:]` pooled over features, so the prediction at row `i` is a
function of `(x_i, D_{<i}, θ)` and nothing else, and **all n prequential terms
come out of ONE forward pass** — Θ(n³) → Θ(n²) (math/01_setup.md §7). A BOS
context row is prepended so row 0 has a non-empty key set (otherwise softmax
over an all-masked row is NaN).

### Leakage test (built into `model.py`, run before any training)
| perturbation | |Δlogit| at that row | required |
|---|---|---|
| flip `y_5`, read row 5 | **0.000e+00** | exactly 0 |
| flip `y_5`, read row 4 | **0.000e+00** | exactly 0 |
| flip `y_5`, read row 6 | 8.716e-02 | > 0 |

Exact zeros, not small numbers. The causal structure is a property of the mask,
not of training.

### Scale actually used
11.21M params (dm=256, nl=12, nh=8), 30 000 steps, batch 8 datasets/step, context
length resampled per step from [256, 512], d_max=32, ≤10 classes. **244 min on
one GPU.** Batch 16 OOMs because an unrelated service holds ~10 GiB; this is a
budget limitation to state, not a design choice.

## 20. Scoring `R_fit` (`pfnfit/score.py`)

Every real dataset `D_m` becomes a K-vector

```
logL[m,k] = (1/|P|) Σ_{σ∈P} Σ_i log q(y_σ(i) | x_σ(i), D_σ(<i), θ_k)
```

which is exactly the object Theorems 3 and 5 consume. Averaging over a small
ordering set `P` is the fix for Warning 2.3 (order dependence): the reported
score is an **average of exact prequential scores**, never an approximation to a
marginal likelihood.

Atoms are **scrambled Sobol** points in [0,1]^12 (K=256): a low-discrepancy set
covers the cube far more evenly than iid uniform at equal K, and the NPMLE is
invariant to how the support was drawn.

Real tables are mapped into the *same* representation the prior emits (median
imputation → per-column z-score → padding + feature mask). Rows are subsampled
to exactly n=512 for **every** dataset, with replacement when the table is
shorter, so a long dataset cannot earn a larger `logL` merely by contributing
more terms.

### Smoke check on 8 `R_dev` datasets (K=32, P=1), nats/row
| did | best atom | atom mean | worst atom | θ-spread |
|---|---|---|---|---|
| 1021 | **−0.144** | −0.215 | −0.273 | 0.129 |
| 41006 | −0.329 | −0.431 | −0.512 | 0.183 |
| 44570 | −0.390 | −0.406 | −0.422 | 0.031 |
| 1073 | −0.510 | −0.516 | −0.523 | 0.013 |
| 44657 | −0.675 | −0.678 | −0.681 | 0.006 |
| 44495 | −0.698 | −0.700 | −0.703 | 0.005 |
| 1044 | −1.033 | −1.037 | −1.043 | 0.010 |
| 44517 | −1.222 | −1.253 | −1.282 | 0.060 |

Two things are being checked here, both threats from the register:

**T-A (score dominated by network error).** Binary datasets score up to −0.144
nats/row against a `log(1/2) = −0.693` uniform baseline, so the 11M-param model
does learn real tables in-context. The two rows near −1.0 and −1.2 are
multi-class; they are still far above `log(1/10) = −2.303`.

**T-B (θ ignored).** The θ-spread is 0.005–0.183 nats/row, i.e. **2.5–94 nats
per dataset** at n=512. That is not noise on the scale at which the NPMLE
operates, so the score does discriminate between θ. It is also *small on a
per-row basis*, which is the honest statement of how much of the total
predictive performance the prior choice controls — and it directly bounds what
E1 can possibly show.

Full run: 610 `R_fit` datasets × 256 atoms × 2 orderings, ≈ 2.5 h.
